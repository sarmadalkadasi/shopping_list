# Shopping List App

A Flutter application demonstrating how to work with Flutter Forms, input validation, HTTP requests using the `http` package, and backend data synchronization with Firebase Realtime Database.

## Features

- **Form Validation & Inputs:** Custom fields for item name, quantity, and category selection.
- **Backend Integration:** REST API integration with Firebase Realtime Database.
- **Swipe to Delete:** Dismissible list items with automatic backend synchronization and error rollback.
- **State & Loading Management:** Handles loading states, error dialogs, and dynamic list rendering.

## Getting Started

1. **Clone or Fork the Repository:**
   ```bash
   git clone https://github.com/your-username/shoping_list.git
   cd shoping_list
   ```

2. **Install Dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the Application:**
   ```bash
   flutter run
   ```
